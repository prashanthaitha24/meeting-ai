Not sure which path? Start from what you enjoy.

Careers feel overwhelming when you look at the job titles first. It is far easier to start from what you like doing, see what to study to get there — a degree, a bootcamp, or self-taught — and which careers it opens. Here is that map, and every path has a free course you can start today.

How to read this

Every path has the same three steps

You do not need it all figured out. You need the next step. This is the shape of every path below.

Find your path

Pick the row that sounds like you

Follow it left to right. The middle step links to a free course here so you can try the path before committing to it.
