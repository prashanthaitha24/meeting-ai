Capstone project

Run a game day

Take any service you can deploy (the DevOps capstone works well) and make it production-grade:

  • Write SLOs for availability and latency, with an error budget policy
  • Instrument it with OpenTelemetry; dashboards in Grafana
  • Add multi-window burn-rate alerts in Prometheus
  • Break it on purpose, respond using your runbook, publish the postmortem

The on-call copilot
