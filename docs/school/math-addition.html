Adding: putting groups together

Adding means putting things together to find how many there are altogether. If you have some toys and a friend gives you more, adding tells you how many you have now. This gentle lesson shows adding with pictures first, then the quick way to count on.

Adding is putting together

When we add, we join two groups and count them all. The plus sign + means 'and', and the equals sign = means 'is the same as'. So 3 + 2 means 'three things and two more things', and it equals 5.

Look at the picture: three dots and two more dots make five dots when we count them all together.

Counting on

You don't always have to count every dot from the start. A quicker way is to count on: start at the bigger number and count up by the smaller one. For 4 + 3, start at 4 and count on three more — 5, 6, 7. The answer is 7.

Counting on your fingers is a great way to do this. Hold up the first number, then count on the second number one finger at a time.

Worked example
What is 4 + 3?
  1. Start at the bigger number: 4.
  2. Count on 3 more: 5, 6, 7.
  3. Where you stop is the answer.
Answer: 4 + 3 = 7

A helpful trick: order doesn't matter

Here is something nice about adding: you can add in any order and get the same answer. 2 + 5 is the same as 5 + 2 — both make 7. So you can always start with the bigger number to make counting on easier.

This means if you know 3 + 4 = 7, you also already know 4 + 3 = 7. Learning one fact gives you two.

Check yourself

Try these. Pick an answer to see whether it's right and why.

What does the + sign mean?
The plus sign + means add — put the groups together and count them all.
What is 3 + 2?
Three and two more makes five: 3 + 2 = 5.
To add 5 + 2 by counting on, where do you start?
Start at the bigger number (5) and count on the smaller one: 6, 7. So 5 + 2 = 7.
If 6 + 3 = 9, what is 3 + 6?
Order doesn't matter in adding, so 3 + 6 is also 9.
What is 4 + 4?
Four and four more makes eight: 4 + 4 = 8.

In a nutshell

  • Adding means putting groups together and counting them all; + means 'and', = means 'is the same as'.
  • You can 'count on' from the bigger number instead of counting everything from the start.
  • Order doesn't matter: 2 + 5 is the same as 5 + 2.
