Measuring: long, heavy, and full

Measuring means finding out how big, how heavy, or how much something is. Which pencil is longer? Which bag is heavier? Which cup holds more? This lesson starts with comparing things, then shows how we use units so everyone gets the same answer.

Comparing without numbers

Before we use numbers, we can just compare two things. For length we ask which is longer or shorter. For weight, which is heavier or lighter. For how much a container holds (capacity), which is fuller or holds more. To compare lengths fairly, line the two things up at the same starting point and see which one sticks out further.

In the picture, the pencil bar is longer than the crayon bar, so the pencil is longer.

Measuring with units

Saying 'longer' is useful, but to say how much longer we need units — equal-sized things we count. You could measure a desk in paperclips or hand-spans: 'the desk is 8 paperclips long'. The rule is that every unit must be the same size, and they must line up end to end with no gaps.

The trouble with paperclips and hand-spans is that everyone's are different, so we'd all get different answers. That's why we have standard units that never change — like centimetres and metres for length, grams and kilograms for weight, and litres for how much a container holds.

Worked example
A book is measured as 6 paperclips long. What must be true about the paperclips?
  1. Units used to measure must all be the same size.
  2. They must be placed end to end with no gaps and no overlaps.
  3. So all 6 paperclips must be identical and lined up neatly.
Answer: All the paperclips must be the same size, lined up end to end.

The right tool and the right unit

Different things need different tools. We use a ruler or tape for length, a balance or scales for weight, and a measuring cup or jug for capacity. We also pick a unit that fits: you'd measure a pencil in centimetres but a room in metres, because using tiny units for big things means counting forever.

Measuring well is a real-life skill — cooking, building, and shopping all need it — and it all starts with comparing and counting equal units.

In a nutshell

  • Compare first: longer/shorter for length, heavier/lighter for weight, holds more/less for capacity.
  • To measure how much, count equal-sized units placed end to end with no gaps.
  • Standard units (cm, m, grams, kg, litres) never change, so everyone gets the same answer.
  • Use the right tool and a unit that fits the size of the thing.
